# SoraMotion (Mai · 舞)

SoraMotion is CuteClaudia's motion graphics app, part of the SoraSpace suite (https://www.soraspace.studio).
This repository holds its published versions: download them from **Releases**, and report
problems or send feedback under **Issues**. Installed copies check here for updates.

SoraMotion is built on EffectCraft (MIT OR Apache-2.0); see the NOTICE file in each download.
